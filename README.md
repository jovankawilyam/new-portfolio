# Jovanka Portfolio

An immersive personal portfolio built with Next.js, Tailwind CSS, Motion, and a scroll-driven image sequence.
Built to present selected projects, visual direction, and contact details in a polished single-page experience.

## Features

- **Cinematic Scrollytelling**: Image sequence powered by HTML5 Canvas and scroll synchronization.
- **Smooth Momentum Scrolling**: Integrated `Lenis` for a buttery smooth experience.
- **Advanced Animations**: Powered by `motion` (formerly framer-motion) v12.
  - Staggered reveals
  - Split-text scroll effects
  - Count-up statistics
  - Full-screen animated navigation
- **Responsive Design**: Mobile-first approach with custom layouts for phone and desktop (e.g., Bento Grid adaptation).
- **Performance**: Optimized asset loading and canvas rendering.

## Tech Stack

- **Framework**: [Next.js 16](https://nextjs.org/) (App Router)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Animation**: [Motion](https://motion.dev/)
- **Fonts**: [Outfit](https://fonts.google.com/specimen/Outfit) (Google Fonts)

## Getting Started

1. **Clone the repository**:

   ```bash
   git clone <your-repository-url>
   cd new-portfolio
   ```

2. **Install dependencies**:

   ```bash
   npm install
   ```

3. **Run the development server**:

   ```bash
   npm run dev
   ```

4. **Build for production**:
   ```bash
   npm run build
   ```

## Customization

Update placeholder contact links, project details, and social URLs before publishing.
